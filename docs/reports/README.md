Отчёты фиксируют условия и результат конкретного замера. Они не являются
инструкциями по запуску и не должны использоваться как источник текущей
конфигурации.

| Отчёт | Дата/контекст |
| --- | --- |
| [Observability](observability.md) | внедрение и проверка локального monitoring stack, июль 2026 |
| [Масштабируемость](scalability.md) | локальные Docker Desktop/Locust замеры |

Актуальные команды находятся в разделах [тестирования](../testing/README.md) и
[наблюдаемости](../monitoring/README.md).
